## 1. Overview and Testing Philosophy

The HopTrace backend testing strategy enforces strict correctness, contract compliance, and failure honesty:
- **No False Claims / Honest Failure:** When an external dependency (Neo4j, Sarvam AI) is offline or unconfigured, endpoints return HTTP 503 instead of fabricating data.
- **Evaluation Separation:** The diagnostic engine inferring root cause never receives the injected fault label or scenario name.
- **Contract Adherence:** All responses strictly follow [`docs/api-contract.md`](file:///Users/rahulrajput/Documents/HopTrace/docs/api-contract.md).
- **Fast and Offline-First:** 167 out of 169 tests run completely offline in under 1 second using an in-memory graph mirror and temporary SQLite instances.

## 4. External Integration Tests & Prerequisites

Two tests in `tests/engine/test_neo4j_integration.py` test live Neo4j database interaction:
1. `test_neo4j_live_idempotent_seeding`
2. `test_neo4j_live_subscriber_dependencies`

### Prerequisites for Running Live Neo4j Tests:
1. A running Neo4j instance (Aura cloud or local Neo4j desktop).
2. Set credentials in `.env`:
   ```bash
   NEO4J_URI=bolt://localhost:7687  # or neo4j+s://<dbid>.databases.neo4j.io
   NEO4J_USERNAME=neo4j
   NEO4J_PASSWORD=<your_actual_password>
   ```
3. Run tests with live flag:
   ```bash
   backend/.venv/bin/python -m pytest tests/engine/test_neo4j_integration.py -v
   ```

### Known Skipped Tests and Why They Are Skipped:
When running the standard test suite without a live Neo4j instance, these 2 tests produce:
```
tests/engine/test_neo4j_integration.py::test_neo4j_live_idempotent_seeding SKIPPED
tests/engine/test_neo4j_integration.py::test_neo4j_live_subscriber_dependencies SKIPPED
```
**Reason for Skip:**  
Both tests inspect `HopTraceEngine.is_neo4j_available()`. If the Neo4j driver cannot establish an active session, the tests invoke `pytest.skip("Live Neo4j instance not reachable")`.  
This ensures:
- The CI pipeline and local developers can run all 144 unit tests offline without spinning up a live Neo4j database.
- Offline execution never produces false failures.
